# Boxme OMS API

Página pública da API do Boxme OMS (OMS/Hub/Integrador multi-tenant da Boxme).

O contrato OpenAPI e o código ficam no repositório privado `brunoconstantino/boxme-oms`
(`specs/openapi-v1.yaml` e `specs/api-v1.md`) e serão publicados aqui quando a versão do app
da API estiver aprovada.

- Endereço da API: `https://oms.boxme.log.br/api/v1` (em construção)
- Autenticação: Bearer token por tenant, emitido no painel do OMS
- Contato: Boxme — https://boxme.log.br
